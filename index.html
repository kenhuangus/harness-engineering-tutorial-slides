Core Thesis

Probabilistic Model vs. Deterministic Control Plane

Autonomous search (hill-climbing) requires an objective function, bounded actions, state preservation, and rollback hooks — not an unmonitored loop.

Probabilistic ModelProposes Actions

  • • Non-Deterministic Generation: The foundation model selects actions probabilistically from runtime context and prompts.
  • • Vulnerable Failure Modes: Prone to amnesia, prompt injection, intent drift, recursive retry loops, and unverified code edits.
  • • Why Prompts Fail: Prompts cannot enforce least privilege, verify delegation chains, persist tamper-evident traces, or guarantee rollback.

Deterministic HarnessGoverns Execution

  • • Mediated Authority: The control plane dictates what agents may know, remember, decide, delegate, execute, and observe.
  • • Deterministic Interception: Evaluates every tool call through five invariant layers: Identity, Purpose, Context, Memory, and Runtime Policy.
  • • Forensic Evidence: Generates tamper-evident SHA-256 envelopes, audit checkpoints, and immutable tombstones.
